# KI Literacy Basics · HTML-Präsentation (Erweitert)

Diese interaktive Präsentation bietet eine fundierte Einführung in die Grundlagen der Künstlichen Intelligenz (KI-Literacy) für Studierende im ersten Semester. Sie ist als portable, vollständig offline-fähige HTML-Foliensammlung aufgebaut.

## Schnellstart

- **Präsentation starten:** Öffne die Datei [presentation.html](file:///Users/matmax/Library/Mobile%20Documents/com~apple~CloudDocs/BrainVault/CampusHub/projects/Automatismen/Pr%C3%A4sentationen/KI%20Literacy%20Basics/presentation.html) per Doppelklick im Webbrowser. Sie leitet automatisch auf die deutsche Version [presentation.de.html](file:///Users/matmax/Library/Mobile%20Documents/com~apple~CloudDocs/BrainVault/CampusHub/projects/Automatismen/Pr%C3%A4sentationen/KI%20Literacy%20Basics/presentation.de.html) weiter.
- **Review-Modus:** Öffne [review.html](file:///Users/matmax/Library/Mobile%20Documents/com~apple~CloudDocs/BrainVault/CampusHub/projects/Automatismen/Pr%C3%A4sentationen/KI%20Literacy%20Basics/review.html) im Browser, um die Präsentation zu sichten, Feedback zu protokollieren oder Bildausschnitte anzupassen.

## Navigation und Steuerung

- **Folien wechseln:**
  - `Pfeiltaste Rechts` / `Leertaste` / `Bild ab` → Nächste Folie
  - `Pfeiltaste Links` / `Bild auf` → Vorherige Folie
  - `Pos 1 (Home)` → Erste Folie
  - `Ende (End)` → Letzte Folie
  - Klicks auf die Schaltflächen `←` und `→` im Navigationsbalken unten rechts.
- **Farbschema:** Ein Klick auf das Symbol `◐ Auto` (oder `◑ Dark` / `◒ Light`) im Navigationsbalken wechselt das Theme (Systemeinstellung, Darkmode, Lightmode).
- **Druckansicht:** Verwende die Standard-Druckfunktion deines Browsers (`Cmd+P` / `Strg+P`). Die Stylesheets blenden alle NavigationsHUDs aus und zeigen alle 35 Folien untereinander in hellem Kontrastdruck an.

## Interaktive Elemente

- **Folie 11 (Generalisieren vs. Auswendiglernen):** Option-Buttons veranschaulichen Overfitting im Vergleich zu echtem Transferwissen.
- **Folie 16 (Halluzinationen):** Ein Klick auf "Warum erfindet das LLM?" blendet das didaktische Feedback ein.
- **Folie 17 (Kontextfenster):** Ein stufenloser Schieberegler veranschaulicht das Phänomen "Lost in the Middle" bei wachsendem Arbeitsfenster (4k bis 128k Tokens) mit dynamischer Umrechnung in DIN A4-Seiten und Harry Potter Bücher.
- **Folie 19 (RAG & Memory):** Ein interaktiver Reveal hinterfragt das Heilsversprechen von RAG bezüglich absoluter Wahrheitsgarantie.
- **Folie 20 (Kochmetapher):** Ein Klick auf "Und die Küche?" deckt die Metapher für das Kontextfenster auf.
- **Folie 23 (Additive vs. Subtraktive Kreativität):** Buttons definieren Additive Kreativität (Token-Häufung/Textmodelle) und Subtraktive Kreativität (Denoising/Bildmodelle).
- **Folie 33 (Mini-Quiz):** Drei Wissensfragen mit direkter Button-Rückmeldung erlauben eine kurze Lernerfolgskontrolle im Plenum vor dem Fazit.
